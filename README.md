# Rafiki Chatbot 0.6.1

PWA de recordatorios con Gemini como intérprete principal, validación propia de acciones y Firebase para autenticación y almacenamiento privado.

Consulta [RELEASE_0.6.1.md](RELEASE_0.6.1.md) para el flujo, requisitos, configuración y pruebas. Esta entrega no se ha desplegado.

La demostración utiliza Agent Core localmente. Para Gemini se necesita una cuenta Firebase activa y el endpoint protegido del servidor. No introduzcas credenciales en el chat ni en variables con prefijo VITE_.
